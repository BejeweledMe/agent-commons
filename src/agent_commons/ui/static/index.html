    What each profile actually receives

    SGR — Schema-Guided Reasoning

    How roles hand back structured results today

    Through typed outcome tools: a role finishes a run by calling commons_succeed_delegation with a typed result reference, and a reviewer records its verdict through commons_complete_review. That is the only typed result channel on subscription CLIs — provider stdout is never parsed or stored, by design.

    MCP

    agent-commons — built in

    Every run talks to headquarters only through this stdio server. External MCP configs are disabled on purpose: Claude runs under --strict-mcp-config with no setting sources, Codex ignores user config entirely. What each profile may call is listed under Tools.
