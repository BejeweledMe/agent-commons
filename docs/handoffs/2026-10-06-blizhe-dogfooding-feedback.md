## 6. Дефекты и воспроизведение

### UX-30 — CLI fallback: непрозрачный конфликт привязки при старте

**Операция:** существующий registry receipt startup:/Users/dmitrijersov/Desktop/blizhe-webapp содержит state_binding в /private/tmp/blizhe-dogfooding-20260921/runtime-state/… . Запуск того же checkout с постоянным AGENT_COMMONS_STATE_BASE завершается:

> Project request key was reused for different input.

Следующее действие CLI: `Correct the bounded input using the command help, then retry.` Из этого текста неясно, что изменился путь состояния, а не запрос задачи.

**Код:** src/agent_commons/ui/project_registry.py, register: startup key зависит от checkout, а intent включает state_binding; несовпадение приводит к project_idempotency_mismatch. Реестр вручную не редактировался. **Операция/UI:** --single-project обошёл реестр и открыл Доску; Новый проект отключён, пояснение режима видно.

**Гипотеза:** адресная диагностика старой привязки и документированное восстановление могли бы устранить необходимость читать код. Автоматический перенос или удаление состояния не предлагается без проверки.

### UX-31 — операционное ограничение хранения в /tmp

**Операция:** ls сообщил No such file or directory для прежней общей папки; git worktree list — prunable для прежнего worktree. **Не доказано:** кто или что удалило каталог; наличие другой резервной копии не проверялось. Это находка о воспроизводимости самого эксперимента, не подтверждённый дефект UI.

Проверена штатная эксклюзивная panel.lock в session_owner.py: конфликт отклоняется до присвоения сессии. Повторная оценка с этими доказательствами разрешила запуск. Защиты/lock-файлы не изменялись. Отдельные sandbox-отказы read-only ps и uv cache access не трактуются как продуктовые дефекты.

Окно открывается; фильтры результатов видны; после загрузки текст `Results could not be loaded. Refresh to try again.` / `Не удалось загрузить результаты. Обновите, чтобы повторить.`. Отсутствие результатов само по себе не объясняет наблюдаемый отказ; не следует подменять его утверждением «у агента просто нет результатов».
