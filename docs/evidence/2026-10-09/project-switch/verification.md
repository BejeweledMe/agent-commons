# Переключение проектов: проверка и публикация

Дата: 2026-10-09. База исправления: `9ff2ce55ecb1d46875408c9b6c0f65b7efc76125`.
Точные исходники, тесты, документация и поставляемые ресурсы: [manifest v2](review-manifest-v2.json).

## Причина и поведение

При выборе проекта `checking` заменял всё приложение экраном «Проверяем защищённый доступ». Загрузка повторно проверяла подключение к хосту, перечитывала реестр проектов и ждала наблюдений о провайдерах до первого отображения рабочего пространства.

Теперь во время загрузки остаются список проектов, навигация и имя выбранного проекта. Данные предыдущего проекта не показываются. Подключение и реестр переиспользуются при обычной навигации; явное обновление проверяет подключение заново и перечитывает реестр. Проверки провайдеров догружаются отдельно и не означают готовность, пока ответ не получен. Запоздавшие ответы проверяют выбранный проект и поколение запроса.

Первое независимое ревью обнаружило, что после перезапуска сервера уже подключённый клиент мог сохранять устаревший API prefix. Исправлено: явное обновление, новый локальный вход и ошибка 404 при начальной загрузке проверяют хост. Ошибка отсутствующей сущности на действующем хосте не сбрасывает подключение. [Первое ревью](source-review-v1.md) сохранено как история; оно не одобряет окончательную версию.

## Браузерная проверка

Chrome, реальная локальная панель на порту 8794; проекты Agent Commons и Blizhe. Браузер оставался на пользовательском масштабе 80%; проверка узкого режима использовала 800 CSS px и затем вернула исходный размер.

- До исправления: полный экран проверки, навигации нет; один контрольный поиск кнопки не дождался её примерно за 6 секунд. Замер 8511 мс включает промежуток между инструментальными вызовами и не является точным временем загрузки.
- После исправления: навигация сохранялась при быстрых A→B→A→B, включая незавершённую загрузку. Для финальной сборки первый снимок после перехода доступен через 340 мс; обратный переход записан отдельно. Это время наблюдения доступной навигации, не полного получения данных карты.
- После завершения загрузки показаны 14 задач Blizhe и его получатель главного чата. Данные Agent Commons не оставались в этой области.
- В узком режиме можно открыть список проектов во время загрузки; закрытие крестиком и Escape работает. Переключение «Задачи»/«Агенты» не запускает проверку проекта.
- В проверенной вкладке ошибок консоли не обнаружено. Физический перезапуск работающего пользовательского сервера не проводился; сценарии восстановления проверены настоящим скомпилированным WorkApi с воспроизводимыми ответами сервера.
