# Реализация решений UI/UX-консилиума — 9 октября 2026

В локальном checkout реализована волна UX-01–19 из [согласованного графа действий](../../../archive/plans/2026-10-09-ux-council-implementation.md). Изменения собраны в поставляемые ресурсы Work/Gallery, установленный пакет обновлён, обычная панель на `127.0.0.1:8794/work` перезапущена и проверена. Git commit, push и публикация этой волной не выполнялись.

## Кто участвовал

Независимые исходные разборы Sol 6.1, Sonnet 5.5 и Grok 4.7 сохранены в [аудите](../design-council/README.md). Sol и Sonnet обменялись замечаниями и согласовали [план](README.md). При повторном обсуждении Grok был недоступен по недельному лимиту до 13 октября; его исходный разбор учтён, нового ответа или единогласия трёх моделей нет.

Opus через Claude CLI начал реализацию: семантические уровни масштаба, карты, компоновка найма и часть действий агентов. Во второй попытке сработал лимит сессии Claude до 20:40 MSK. Частичные изменения сохранены; Codex завершил интеграцию, настройки, выбор задачи, окна, локаль, статусы и проверки. [Происхождение первой попытки](opus-wave1.json) и [второй](opus-wave2.json) не подменяются успешностью последующих проверок. После переустановки пакета новый [реальный canary профиля Opus](opus-canary-final.json) завершился успешно за 76,59 с, дочерняя сессия закрыта. `opus` — запрошенный alias, не доказательство точного backend model ID.

## Проверки

Полный `make check` на окончательных исходниках и ресурсах: **exit 0**, Work **513 passed**, Gallery **27 passed**, Python **3034 passed, 14 skipped, 2 warnings**, 934,96 с. Пропуски: необязательный большой performance benchmark, ранее удержанные автоматические полномочия, CI-only проверка. Предупреждения Python относятся к TestClient/Starlette. TypeScript обеих программ прошёл. [Сводка и хеш полного журнала](checks.json).

Первый общий прогон был запущен до завершения последних исходных исправлений и поймал ожидаемое несовпадение исходников с bundle; после окончательной сборки выполнен новый полный прогон. Итог выше относится только к финальному прогону, а не к объединению частичных результатов.

Независимое ревью проводилось отдельными сессиями при остановленных изменениях checkout и ledger. [v1](review-v1.md) нашло P2: одинаковые доступные имена на далёкой карте. [v2](review-v2.md) подтвердило исправление и выявило P2: фиксированный минимум 20% обрезал большое дерево агентов. Оба исправлены. [v4](review-v4.md) одобрило точную финальную дельту; 173 хеша снимка совпали и 59 адресных проверок прошли. Последующая архивация плана и добавление этого отчёта — только документационные изменения; проверенные исходники и ресурсы не менялись. Ревью кода не подменяет пользовательскую оценку удобства.

Браузер: Chrome на Mac; измеренные ширины **1280, 1101, 1100, 800, 390 CSS px**, отдельный короткий desktop **1280×600**. Горизонтального переполнения документа не наблюдалось. Точные [измерения](browser/geometry-observations.json) важнее запрошенного размера эмуляции: существующий browser zoom влиял на пересчёт, «100% browser zoom проверен» не заявляется. Ошибок приложения в [консоли](browser/console-observations.json) не наблюдалось; на одной тестовой вкладке была ошибка расширения Grammarly, она не приписывается приложению.

В [журнале записей](ui-mutations.jsonl) синтетического проекта: запись версии методов, её привязка к агенту, отдельная запись общих настроек и сообщение. [До](checkpoint-before-settings.json) и [после неизменённых настроек](checkpoint-after-settings-noop.json) canonical hashes совпадают. Реальный Blizhe использовался только для чтения; тестовые записи выполнялись в отдельных временных пространствах. Выбор языка и просмотр карты не меняют задачи/агентов.

## Оставшиеся границы

Обзор большой карты показывает структуру, а не обещает читаемость каждого из 128 заголовков одновременно: для работы есть выбранный элемент, список/поиск и рабочий масштаб. Два движка карт сохранены. Bundle Work остаётся около 1,10 MB (gzip около 309 KB); Vite предупреждает о размере chunk. Нового заявления о frame rate, latency или результате большого performance benchmark нет.

Эта волна не доказывает полный запуск реальной задачи через каждого провайдера, доставку ответа в чат, наполненные previews или разрешение старых блокеров других проектов. Незавершённые продуктовые программы остаются в своих действующих планах. Локальная сборка доступна для проверки; Git-публикация не выполнялась.
