## Реализовано

Рабочая область состоит из навигации, карты задач и главного чата проекта.
Выбор задачи открывает временные подробности и не меняет адресата главного чата.
Ширина, сворачивание и перестановка боковых панелей сохраняются отдельно для
пользователя и проекта. В компактном окне боковые панели открываются по одной.

Карта поддерживает структуру и зависимости, pan, масштабирование относительно
указателя, клавиатуру, вписывание и текстовый список. Выбранная задача, явно
сфокусированная ветка и положение карты имеют отдельное состояние.

Галерея агента открывается по его имени/аватару. Она показывает сохранённые
изображения, сборки, текстовые отчёты и версии. Описания задач читаются полностью;
доказательства имеют названия и доступны постранично. История прогонов учитывает
дату, включая переход через полночь.

Backend сохраняет ссылки при CLI submit, проверяет общий бюджет до запуска и
повторно при резервировании, создаёт адресованный канал задачи до старта worker,
добавляет специализацию QA и сохранённые текстовые результаты с точной ревизией.
Среда проекта и квалификация провайдера показываются отдельно. Черновики
сохраняются явно, защищены от конфликтов и удаляются после подтверждённой отправки
только при совпадении текста и версии.

Opus создал дизайн и исходную frontend-реализацию. После лимита Claude интеграцию
и исправления завершили Codex-агенты. Это отражено в
[provenance](opus-frontend-provenance.json), а не приписано целиком Opus.

## Запуск для проверки

Текущая панель: <http://127.0.0.1:8794/work>. Если сервер остановлен, из корня
этого checkout:

```bash
make sync
env -u AGENT_COMMONS_STATE_ROOT -u AGENT_COMMONS_STATE_BASE -u AGENT_COMMONS_SESSION_ID \
  .venv/bin/python -m agent_commons --repo "$PWD" \
  --state-root "$PWD/.git/agent-commons-state" ui --port 8794
```

Команда открывает свежую локальную ссылку входа. Старую одноразовую ссылку из
журнала переиспользовать не нужно. В панели: «Карта задач», «Структура» или
«Зависимости»; «Вид» управляет раскладкой. «Доска» → имя агента открывает галерею.

## Границы

Автоматизированные проверки viewport и браузерный wheel/клавиатура не доказывают
ощущение физического pinch на трекпаде. Проверки на macOS не заменяют Linux CI.
Claude после лимита не запускался повторно для реального canary. В синтетическом
UI не запускались платные провайдеры, не имитировались approval или acceptance.
Согласие моделей не является приёмкой задач. Публикация Git и remote CI в эту
локальную границу не входят.
