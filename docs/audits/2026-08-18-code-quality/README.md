# Аудит качества кода Agent Commons — материалы

Цель: навести порядок в кодовой базе. Не «меньше кода», а правильное
количество и правильные границы — где-то разбить, где-то собрать, где-то
дописать то, чего не хватает.

## Мандат (решения владельца, зафиксированы до аудита)

- `CommonsManager` — разросшийся фасад, разбиение разрешено и является
  главным заданием линзы структуры.
- Публичные поверхности (CLI, MCP, роуты панели) менять можно — с описанной
  миграцией и переходной совместимостью.
- `dict[str, Any]` — недоработка везде, включая границы; типизация делается
  в памяти, **формат записанных на диск событий не меняется**.
- Готовность к большой перестройке подтверждена: поток структурных переездов
  планируется целиком, с порядком выполнения.

## Порядок

1. **Прочитать `00-code-standard.md`** и поправить под себя. Это планка,
   по которой судят все ревьюеры и по которой потом отсеивают их находки.
   Полчаса здесь экономят день разбора мусора потом.

2. **Заморозить коммит.** Аудит идёт по одному зафиксированному состоянию,
   после того как сольётся P1. Записать хеш.

3. **Запустить пять линз — параллельно, в отдельных окнах.** Каждая читает
   всё дерево `src/`, а не свой кусок: дефекты живут в связях между модулями.
   - `01-lens-structure.md` — границы, дублирование, карта модулей
   - `02-lens-types.md` — модель данных и типы
   - `03-lens-deadweight.md` — мёртвый вес и недостающее объяснение
   - `04-lens-efficiency.md` — эффективность и память
   - `05-lens-readability.md` — читаемость человеком
   Отчёты кладутся сюда же: `structure-report.md` и так далее.

4. **Свести — `06-synthesis.md`.** Обязательный шаг. Без него получится
   пять отчётов и ни одного плана.

5. **Глубокий проход — только по горячим точкам** из сведения плюс
   безусловно по четырём крупным файлам.

## Два предостережения

**Тесты.** Их не «много» — они распределены неровно. Решение «тест лишний»
принимается по мутационному тестированию (`mutmut`), а не по мнению агента.
Удаление теста необратимо, ошибка агента здесь дороже пользы.

**Комментарии.** 2.8% — это мало. Аудит с установкой «сократить» оптимизирует
в противоположную сторону от нужной.
